# Code Reference

A quick lookup for every type, function and component in the Weather Dashboard. For explanations, see the [Implementation guide](/guides/implementation).

## Types

Defined in `lib/types.ts`.

| Type | Fields | Used for |
| --- | --- | --- |
| `WeatherCondition` | `id`, `main`, `description`, `icon` | One weather condition, such as light rain |
| `WeatherData` | `name`, `sys.country`, `main.temp`, `main.feels_like`, `main.humidity`, `weather`, `wind.speed` | The weather of one city |
| `ApiErrorBody` | `cod`, `message` | The body of an error response |
| `SearchStatus` | `idle`, `loading`, `error`, `success` | Which screen the dashboard shows |

```ts filename="lib/types.ts"
export interface WeatherCondition {
  id: number
  main: string
  description: string
  icon: string
}

export interface WeatherData {
  name: string
  sys: {
    country: string
  }
  main: {
    temp: number
    feels_like: number
    humidity: number
  }
  weather: WeatherCondition[]
  wind: {
    speed: number
  }
}

export interface ApiErrorBody {
  cod: number | string
  message: string
}

export type SearchStatus = 'idle' | 'loading' | 'error' | 'success'
```

| Route | Method | Query parameter | Description |
| --- | --- | --- | --- |

| Function | File | Parameters | Returns |

| `fetchWeather` | `lib/weather.ts` | `city: string` | `Promise<WeatherData>` |

## Weather API request

```text
GET https://api.openweathermap.org/data/2.5/weather?q=Lahore&appid=YOUR_KEY&units=metric
```

| Query parameter | Example | Meaning |
| --- | --- | --- |
| `q` | `Lahore` | City name |
| `appid` | `YOUR_KEY` | Your API key |
| `units` | `metric` | Temperature in Celsius |

## Weather icon URL

```text
https://openweathermap.org/img/wn/10d@2x.png
```

Replace `10d` with the `weather[0].icon` value from the response. The last letter is `d` for day or `n` for night.
