# Code Reference

A quick lookup for every type, function and component used in the Quiz App. For explanations, see the [Implementation guide](/guides/implementation).

## Types

Defined in `lib/types.ts`.

| Type | Shape | Used for |
| --- | --- | --- |
| `Question` | `category`, `type`, `difficulty`, `question`, `correct_answer`, `incorrect_answers` | One quiz question from the API |
| `ApiResponse` | `response_code: number`, `results: Question[]` | The full API response |
| `QuizStatus` | `'idle' \| 'loading' \| 'error' \| 'playing' \| 'finished'` | Which screen the app shows |
| `ScoreEntry` | `categoryName`, `score`, `total`, `date` | One saved result |

```ts filename="lib/types.ts"
export interface Question {
  category: string
  type: 'multiple' | 'boolean'
  difficulty: 'easy' | 'medium' | 'hard'
  question: string
  correct_answer: string
  incorrect_answers: string[]
}

export interface ApiResponse {
  response_code: number
  results: Question[]
}

export type QuizStatus = 'idle' | 'loading' | 'error' | 'playing' | 'finished'

export interface ScoreEntry {
  categoryName: string
  score: number
  total: number
  date: string
}
```

## API functions

Defined in `lib/api.ts`.

| Function | Parameters | Returns |
| --- | --- | --- |
| `fetchQuestions` | `categoryId: number`, `amount = 10` | `Promise<Question[]>` |
| `QuizApiError` | `message: string`, `status?: number` | An `Error` subclass with an optional HTTP `status` |

`fetchQuestions` throws a `QuizApiError` when the network fails, when the HTTP status is not OK, or when `response_code` is not `0`.

## API request format

```text
GET https://opentdb.com/api.php?amount=10&category=9&type=multiple&encode=url3986
```

| Query parameter | Example | Meaning |
| --- | --- | --- |
| `amount` | `10` | Number of questions (1 to 50) |
| `category` | `9` | Category id, see `lib/categories.ts` |
| `type` | `multiple` | `multiple` or `boolean` |
| `encode` | `url3986` | Encodes text so it has no HTML entities |
