# Code Reference

A quick lookup for every type, function, component and request in the Weather Dashboard. For explanations, see the [UI & Styling](/guides/ui-styling) and [Implementation](/guides/implementation) guides.

## Types

Defined in `lib/types.ts`.

| Type | Fields | Used for |
| --- | --- | --- |
| `WeatherCondition` | `id`, `main`, `description`, `icon` | One weather condition, such as light rain |
| `WeatherData` | `name`, `coord`, `timezone`, `sys`, `main`, `weather`, `wind` | The current weather of one city |
| `ForecastItem` | `dt`, `main.temp`, `weather`, `pop` | One forecast step, every 3 hours |
| `ForecastData` | `list` | The raw forecast response |
| `DashboardData` | `current`, `forecast` | What your own route returns |
| `RecentCity` | `name`, `country`, `temp`, `icon`, `description` | A saved search |
| `ApiErrorBody` | `cod`, `message` | The body of an error response |
| `SearchStatus` | `idle`, `loading`, `error`, `success` | Which screen the dashboard shows |

### Fields you will use most

| Field | Type | Meaning |
| --- | --- | --- |
| `WeatherData.main.temp` | `number` | Temperature in Celsius |
| `WeatherData.main.feels_like` | `number` | Feels-like temperature in Celsius |
| `WeatherData.main.humidity` | `number` | Humidity in percent |
| `WeatherData.main.pressure` | `number` | Pressure in hPa |
| `WeatherData.wind.speed` | `number` | Wind speed in meters per second |
| `WeatherData.sys.sunrise`, `sunset` | `number` | Unix time in seconds (UTC) |
| `WeatherData.timezone` | `number` | The city's offset from UTC, in seconds |
| `WeatherData.weather[0].icon` | `string` | Icon code such as `10d`. The last letter is `d` (day) or `n` (night) |
| `ForecastItem.dt` | `number` | Unix time of the forecast step, in seconds (UTC) |
| `ForecastItem.pop` | `number` | Chance of rain from 0 to 1 |

## Server route

Defined in `app/api/dashboard/route.ts`.

| Route | Method | Query parameter | Description |
| --- | --- | --- | --- |
| `/api/dashboard` | `GET` | `city` (required) | Calls the weather API twice with your secret key and returns the current weather and the forecast together |

Responses:

| Status | Body | When |
| --- | --- | --- |
| `200` | `DashboardData` | Both requests succeeded |
| `400` | `ApiErrorBody` | `city` is missing or empty |
| `401`, `404`, `429` | `ApiErrorBody` | Passed through from the weather API |
| `500` | `ApiErrorBody` | `OPENWEATHER_API_KEY` is missing on the server |
| `502` | `ApiErrorBody` | The weather service could not be reached |

## Client functions

### `lib/weather.ts`

| Function | Parameters | Returns |
| --- | --- | --- |
| `fetchDashboard` | `city: string` | `Promise<DashboardData>` |
| `messageForStatus` | `status: number` | A readable error message |
| `WeatherApiError` | `message: string`, `status: number` | An `Error` subclass with the HTTP `status` |

`fetchDashboard` throws a `WeatherApiError` when the network fails or the response status is not OK. A network failure has `status` `0`.

### `lib/history.ts`

| Function | Parameters | Returns |
| --- | --- | --- |
| `loadHistory` | none | `RecentCity[]` (empty on the server or on error) |
| `addCity` | `city: RecentCity` | The updated list, newest first, at most 6 entries |

Saved in the browser under the `localStorage` key `recent-cities-v2`.

## Weather API requests

Both requests are made from `app/api/dashboard/route.ts`, never from the browser.

### Current weather

```text
GET https://api.openweathermap.org/data/2.5/weather?q=Lahore&appid=YOUR_KEY&units=metric
```

| Query parameter | Example | Meaning |
| --- | --- | --- |
| `q` | `Lahore` | City name |
| `appid` | `YOUR_KEY` | Your API key |
| `units` | `metric` | Temperature in Celsius, wind in meters per second |

### 5-day forecast

```text
GET https://api.openweathermap.org/data/2.5/forecast?lat=31.5497&lon=74.3436&appid=YOUR_KEY&units=metric
```

| Query parameter | Example | Meaning |
| --- | --- | --- |
| `lat`, `lon` | `31.5497`, `74.3436` | Coordinates, taken from the current weather response |
| `appid` | `YOUR_KEY` | Your API key |
| `units` | `metric` | Temperature in Celsius |

The response contains a `list` of 40 steps, one every 3 hours, for 5 days.

## Weather icon URL

```text
https://openweathermap.org/img/wn/10d@2x.png
```

Replace `10d` with the `weather[0].icon` value from the response. Use `@2x` for a larger image, or leave it out for a small one (`10d.png`).
