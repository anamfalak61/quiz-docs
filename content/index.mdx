## What you will learn

- Setting up a strict TypeScript Next.js project
- Keeping an API key safe with `.env.local` and a server route
- Styling a responsive dashboard with Tailwind CSS
- Showing dynamic weather icons that match the current conditions
- Fetching data with `fetch` or `axios`, with typed API responses
- Handling loading, error, 401 and 404 states
- Searching by city and saving recent searches
