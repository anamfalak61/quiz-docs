# Build a Weather Dashboard with Next.js

This documentation teaches you, step by step, how to build a Weather Dashboard with **Next.js (App Router)**, **TypeScript** and **Tailwind CSS**. The app searches the weather of any city, shows it on a card with a dynamic weather icon, handles loading and errors, and remembers your recent searches.

  The most important idea in this guide: your API key stays on the server. The browser talks to your own route, and only that route knows the key.
</Callout>

## What you will learn

- Setting up a strict TypeScript Next.js project
- Keeping an API key safe with `.env.local` and a server route
- Styling a responsive weather card with Tailwind CSS
- Showing dynamic weather icons that match the current conditions
- Fetching data with `fetch` or `axios`, with typed API responses
- Handling loading, error, 401 and 404 states
- Searching by city and saving recent searches
