# Implementation

In this guide we connect the Quiz App to the **Open Trivia DB API**. You will build typed API calls, loading and error states, category selection, a quiz flow, and a recent scores history.

## 1. Extend the types

Add the new types to `lib/types.ts`, below the `Question` and `ApiResponse` types from the setup guide:

```ts filename="lib/types.ts"
export type QuizStatus = 'idle' | 'loading' | 'error' | 'playing' | 'finished'

export interface ScoreEntry {
  categoryName: string
  score: number
  total: number
  date: string // ISO string
}
```

`QuizStatus` lists every screen the app can be on. Because it is a union type, TypeScript will warn you if you forget to handle one of them.

## 2. Fetch questions

Create `lib/api.ts`. It builds the URL, checks the response, and converts every failure into a readable `QuizApiError`.

```ts filename="lib/api.ts"
import type { ApiResponse, Question } from '@/lib/types'

const BASE_URL = process.env.NEXT_PUBLIC_TRIVIA_API_URL

export class QuizApiError extends Error {
  status?: number

  constructor(message: string, status?: number) {
    super(message)
    this.name = 'QuizApiError'
    this.status = status
  }
}

function messageForStatus(status: number): string {
  if (status === 429) return 'Too many requests. Please wait a few seconds and try again.'
  if (status === 404) return 'The quiz service could not be found.'
  return `Request failed with status ${status}.`
}

function messageForCode(code: number): string {
  switch (code) {
    case 1:
      return 'Not enough questions in this category. Please choose another one.'
    case 2:
      return 'The request had an invalid parameter.'
    case 5:
      return 'Too many requests. Please wait a few seconds and try again.'
    default:
      return 'The quiz service returned an unexpected response.'
  }
}

function decodeQuestion(q: Question): Question {
  return {
    ...q,
    category: decodeURIComponent(q.category),
    question: decodeURIComponent(q.question),
    correct_answer: decodeURIComponent(q.correct_answer),
    incorrect_answers: q.incorrect_answers.map(decodeURIComponent),
  }
}

export async function fetchQuestions(categoryId: number, amount = 10): Promise<Question[]> {
  if (!BASE_URL) {
    throw new QuizApiError('API URL is missing. Check your .env.local file.')
  }

  const url = `${BASE_URL}?amount=${amount}&category=${categoryId}&type=multiple&encode=url3986`

  let response: Response
  try {
    response = await fetch(url)
  } catch {
    throw new QuizApiError('Network error. Please check your internet connection.')
  }

  if (!response.ok) {
    throw new QuizApiError(messageForStatus(response.status), response.status)
  }

  const data: ApiResponse = await response.json()

  if (data.response_code !== 0) {
    throw new QuizApiError(messageForCode(data.response_code))
  }

  return data.results.map(decodeQuestion)
}
```

A few things worth noticing:

- `encode=url3986` asks the API to URL-encode text. Without it, questions contain HTML entities such as `&quot;` and `&#039;`.
- The API can return **HTTP 200** and still fail. The real result is in `response_code`, where `0` means success.
- `response.ok` is `false` for 4xx and 5xx statuses, but `fetch` does **not** throw for them. You must check it yourself.

<Callout type="warning">
  The Open Trivia DB allows about **one request every 5 seconds per IP address**. If you click too fast you will get HTTP 429, which our error handling turns into a friendly message.
</Callout>

### The same call with axios

If you prefer `axios`, the request looks like this. It throws automatically for 4xx and 5xx statuses.

```ts filename="lib/api.axios.ts"
import axios, { AxiosError } from 'axios'
import type { ApiResponse } from '@/lib/types'

export async function fetchQuestionsWithAxios(categoryId: number) {
  try {
    const { data } = await axios.get<ApiResponse>(process.env.NEXT_PUBLIC_TRIVIA_API_URL!, {
      params: { amount: 10, category: categoryId, type: 'multiple', encode: 'url3986' },
    })
    return data.results
  } catch (error) {
    if (error instanceof AxiosError && error.response) {
      console.error('Request failed with status', error.response.status)
    }
    throw error
  }
}
```

## 3. Save recent scores

We store the last five results in the browser with `localStorage`.

```ts filename="lib/history.ts"
import type { ScoreEntry } from '@/lib/types'

const KEY = 'quiz-history'
const MAX_ENTRIES = 5

export function loadHistory(): ScoreEntry[] {
  if (typeof window === 'undefined') return []
  try {
    const raw = window.localStorage.getItem(KEY)
    return raw ? (JSON.parse(raw) as ScoreEntry[]) : []
  } catch {
    return []
  }
}

export function saveScore(entry: ScoreEntry): ScoreEntry[] {
  const updated = [entry, ...loadHistory()].slice(0, MAX_ENTRIES)
  try {
    window.localStorage.setItem(KEY, JSON.stringify(updated))
  } catch {
    // Storage can be full or blocked. The quiz still works without history.
  }
  return updated
}
```

Show the list with a small component:

```tsx filename="components/ScoreHistory.tsx"
import type { ScoreEntry } from '@/lib/types'

export default function ScoreHistory({ entries }: { entries: ScoreEntry[] }) {
  if (entries.length === 0) return null

  return (
    <section className="mt-10">
      <h2 className="mb-3 text-lg font-semibold">Recent scores</h2>
      <ul className="space-y-2">
        {entries.map((entry) => (
          <li
            key={entry.date}
            className="flex items-center justify-between rounded-lg border border-slate-200 bg-white px-4 py-3 text-sm"
          >
            <span>{entry.categoryName}</span>
            <span className="font-semibold">
              {entry.score} / {entry.total}
            </span>
          </li>
        ))}
      </ul>
    </section>
  )
}
```

<Callout type="info">
  `localStorage` does not exist on the server, which is why `loadHistory` checks `typeof window`. We also read it inside `useEffect` in the next step, so the server and browser render the same HTML first.
</Callout>

## 4. Build the quiz page

The page is a small state machine driven by `status`: idle, loading, error, playing and finished.

```tsx filename="app/page.tsx"
'use client'

import { useEffect, useMemo, useState } from 'react'
import CategorySelect from '@/components/CategorySelect'
import QuestionCard from '@/components/QuestionCard'
import ScoreHistory from '@/components/ScoreHistory'
import { fetchQuestions, QuizApiError } from '@/lib/api'
import { CATEGORIES } from '@/lib/categories'
import { loadHistory, saveScore } from '@/lib/history'
import type { Question, QuizStatus, ScoreEntry } from '@/lib/types'

function shuffle<T>(items: T[]): T[] {
  return [...items].sort(() => Math.random() - 0.5)
}

export default function Home() {
  const [status, setStatus] = useState<QuizStatus>('idle')
  const [categoryId, setCategoryId] = useState<number | null>(null)
  const [questions, setQuestions] = useState<Question[]>([])
  const [index, setIndex] = useState(0)
  const [selected, setSelected] = useState<string | null>(null)
  const [score, setScore] = useState(0)
  const [errorMessage, setErrorMessage] = useState('')
  const [history, setHistory] = useState<ScoreEntry[]>([])

  useEffect(() => {
    setHistory(loadHistory())
  }, [])

  const current = questions[index]

  const options = useMemo(
    () => (current ? shuffle([...current.incorrect_answers, current.correct_answer]) : []),
    [current],
  )

  async function startQuiz(id: number) {
    setCategoryId(id)
    setStatus('loading')
    setErrorMessage('')

    try {
      const data = await fetchQuestions(id)
      setQuestions(data)
      setIndex(0)
      setScore(0)
      setSelected(null)
      setStatus('playing')
    } catch (error) {
      setErrorMessage(
        error instanceof QuizApiError ? error.message : 'Something went wrong. Please try again.',
      )
      setStatus('error')
    }
  }

  function handleAnswer(answer: string) {
    if (!current || selected !== null) return
    setSelected(answer)
    if (answer === current.correct_answer) setScore((s) => s + 1)
  }

  function handleNext() {
    if (index + 1 < questions.length) {
      setIndex((i) => i + 1)
      setSelected(null)
      return
    }

    const categoryName = CATEGORIES.find((c) => c.id === categoryId)?.name ?? 'Quiz'
    setHistory(
      saveScore({
        categoryName,
        score,
        total: questions.length,
        date: new Date().toISOString(),
      }),
    )
    setStatus('finished')
  }

  return (
    <div>
      <h1 className="mb-6 text-2xl font-bold sm:text-3xl">Quiz App</h1>

      {status === 'idle' && (
        <>
          <p className="mb-4 text-slate-600">Choose a category to start.</p>
          <CategorySelect selectedId={categoryId} onSelect={startQuiz} />
        </>
      )}

      {status === 'loading' && (
        <p role="status" className="py-12 text-center text-slate-600">
          Loading questions...
        </p>
      )}

      {status === 'error' && (
        <div role="alert" className="rounded-xl border border-red-200 bg-red-50 p-5">
          <p className="mb-4 text-red-800">{errorMessage}</p>
          <button
            type="button"
            onClick={() => (categoryId !== null ? startQuiz(categoryId) : setStatus('idle'))}
            className="rounded-lg bg-red-600 px-4 py-2 text-sm font-medium text-white hover:bg-red-700"
          >
            Try again
          </button>
        </div>
      )}

      {status === 'playing' && current && (
        <>
          <p className="mb-3 text-sm text-slate-600">
            Question {index + 1} of {questions.length} · Score {score}
          </p>
          <QuestionCard
            question={current.question}
            options={options}
            selected={selected}
            correctAnswer={current.correct_answer}
            onAnswer={handleAnswer}
          />
          {selected !== null && (
            <button
              type="button"
              onClick={handleNext}
              className="mt-5 rounded-lg bg-violet-600 px-5 py-2.5 font-medium text-white hover:bg-violet-700"
            >
              {index + 1 < questions.length ? 'Next question' : 'See result'}
            </button>
          )}
        </>
      )}

      {status === 'finished' && (
        <div className="rounded-2xl border border-slate-200 bg-white p-8 text-center shadow-sm">
          <p className="text-slate-600">Your score</p>
          <p className="my-2 text-4xl font-bold">
            {score} / {questions.length}
          </p>
          <button
            type="button"
            onClick={() => setStatus('idle')}
            className="mt-4 rounded-lg bg-violet-600 px-5 py-2.5 font-medium text-white hover:bg-violet-700"
          >
            Play again
          </button>
        </div>
      )}

      <ScoreHistory entries={history} />
    </div>
  )
}
```

### How the pieces work together

<Steps>

### Pick a category

Clicking a card calls `startQuiz(id)`, which sets `status` to `loading` and awaits `fetchQuestions`.

### Handle the result

On success we store the questions and move to `playing`. On failure the `catch` block saves a readable message and moves to `error`.

### Answer and continue

`handleAnswer` locks the card and updates the score. `handleNext` moves on, or saves the score to history after the last question.

</Steps>

<Callout type="warning">
  Always keep the **loading** and **error** states. Without them, a slow network shows a blank page, and a failed request leaves the user stuck with no way to retry.
</Callout>
