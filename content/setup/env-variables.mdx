# Environment Variables

An API key is a password for the weather service. Anyone who has it can use your account, so it must never be written directly in your code or pushed to GitHub.

## Get an API key

1. Create a free account at [openweathermap.org](https://openweathermap.org).
2. Open the **API keys** page in your account and copy your key.

<Callout type="warning">
  A new key can take some time to start working. While it is not active yet, requests fail with a `401` error. Wait a while and try again before assuming something is wrong with your code.
</Callout>

## Create `.env.local`

In the project root (next to `package.json`), create this file:

```bash filename=".env.local"
OPENWEATHER_API_KEY=paste_your_key_here
```

Notice there is **no `NEXT_PUBLIC_` prefix**. That prefix tells Next.js to include the variable in the browser code. Without it, the variable exists only on the server.

| Variable name | Where it is available |
| --- | --- |
| `OPENWEATHER_API_KEY` | Server only (safe) |
| `NEXT_PUBLIC_OPENWEATHER_API_KEY` | Browser too (anyone can read it) |

<Callout type="warning">
  Never add `NEXT_PUBLIC_` to a secret key. It would be bundled into the JavaScript that every visitor downloads.
</Callout>

## Read it in server code

Only server code, such as a Route Handler, can read it:

```ts filename="app/api/weather/route.ts"
const apiKey = process.env.OPENWEATHER_API_KEY

if (!apiKey) {
  throw new Error('OPENWEATHER_API_KEY is not set in .env.local')
}
```

## Keep it out of Git

Check that Git ignores the file. This command prints the file name if it is ignored:

```bash
git check-ignore .env.local
```

The `.gitignore` created by `create-next-app` already ignores `.env*` files. Commit a `.env.example` file instead, with the variable name and no value, so other developers know what to set:

```bash filename=".env.example"
OPENWEATHER_API_KEY=
```

<Callout type="info">
  After changing `.env.local`, stop the dev server and run `npm run dev` again. Otherwise the new value is not loaded.
</Callout>
