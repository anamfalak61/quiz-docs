# Environment Variables

Settings aur secret keys ko code mein seedha likhna khatarnak hai. Unhein `.env.local` file mein rakhte hain.

## `.env.local` banao

Project ke root mein (`package.json` ke saath) ye file banao:

```bash filename=".env.local"
NEXT_PUBLIC_TRIVIA_API_URL=https://opentdb.com/api.php
```

Open Trivia DB ko API key nahi chahiye, is liye yahan sirf base URL hai. Lekin agar koi API key mangti ho to usay is tarah rakho:

```bash filename=".env.local"
# Prefix nahi hai, to ye sirf server par available hai (safe)
SECRET_API_KEY=your_key_here
```

## Code mein kaise use karein

```ts filename="lib/api.ts"
const BASE_URL = process.env.NEXT_PUBLIC_TRIVIA_API_URL

if (!BASE_URL) {
  throw new Error('NEXT_PUBLIC_TRIVIA_API_URL is not set in .env.local')
}
```

## `NEXT_PUBLIC_` ka matlab

| Naam | Kahan dikhta hai |
| --- | --- |
| `NEXT_PUBLIC_API_URL` | Browser mein bhi (sab dekh sakte hain) |
| `SECRET_API_KEY` | Sirf server par (safe) |

<Callout type="warning">
  Secret key par kabhi `NEXT_PUBLIC_` mat lagao. Wo browser ke code mein chali jati hai aur koi bhi usay dekh sakta hai.
</Callout>

## GitHub par mat jane do

`create-next-app` ki `.gitignore` mein `.env*` pehle se hota hai, phir bhi check kar lo. Is ke badle ek `.env.example` file commit karo, jis mein values na hon:

```bash filename=".env.example"
NEXT_PUBLIC_TRIVIA_API_URL=
SECRET_API_KEY=
```

<Callout type="info">
  `.env.local` badalne ke baad dev server band karke dobara `npm run dev` chalao, warna nayi value nahi milti.
</Callout>
