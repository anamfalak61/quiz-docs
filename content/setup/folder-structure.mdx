## What each folder does

| Folder / File | Purpose |
| --- | --- |
| `app/page.tsx` | The dashboard page the user sees |
| `app/layout.tsx` | The page shell: background, width and metadata |
| `app/api/dashboard/route.ts` | A server route that calls the weather API with your secret key |
| `components/SearchBar.tsx` | The city search box |
| `components/CurrentWeather.tsx` | The main card: city, temperature, icon and the °C / °F switch |
| `components/Highlights.tsx` | Chance of rain, wind, humidity and pressure |
| `components/ForecastPanel.tsx` | The hourly and 5-day forecast, plus sunrise and sunset |
| `components/OtherCities.tsx` | Cards for your recent searches |
| `lib/types.ts` | TypeScript types for the API responses |
| `lib/weather.ts` | The function the browser uses to call your route |
| `lib/history.ts` | Saves and loads recent searches |
| `lib/format.ts` | Temperature conversion and time formatting helpers |
| `.env.local` | Your secret API key, never committed to Git |

<Callout type="info">
  The browser never talks to the weather API directly. It calls `app/api/dashboard/route.ts`, and only that file knows the API key. You will build it in the [Implementation guide](/guides/implementation).
</Callout>
