## Kaun sa folder kya karta hai

| Folder / File | Kaam |
| --- | --- |
| `app/` | Pages aur layout (Next.js App Router) |
| `components/` | Dobara use hone wale UI pieces (card, buttons) |
| `lib/api.ts` | API se data lane wala code |
| `lib/types.ts` | TypeScript types (`Question`, `ApiResponse`) |
| `.env.local` | Secret values aur settings, GitHub par nahi jati |

<Callout type="info">
  API wala code aur UI alag rakhna ek achhi aadat hai. Is se agar API badle to sirf `lib/api.ts` badalni parti hai.
</Callout>
