## What each folder does

| Folder / File | Purpose |
| --- | --- |
| `app/page.tsx` | The dashboard page the user sees |
| `app/api/weather/route.ts` | A server route that calls the weather API with your secret key |
| `components/` | Reusable UI pieces: search box, weather card, history list |
| `lib/types.ts` | TypeScript types for the API response |
| `lib/weather.ts` | The function the browser uses to request weather from your route |
| `lib/history.ts` | Saves and loads recent searches |
| `.env.local` | Your secret API key, never committed to Git |

<Callout type="info">
  The browser never talks to the weather API directly. It calls `app/api/weather/route.ts`, and only that file knows the API key. You will build it in the [Implementation guide](/guides/implementation).
</Callout>
