# Folder Structure

The Quiz App is organized so that every folder has one clear job. This makes the code easier to read and easier to change.

## What each folder does

| Folder / File | Purpose |
| --- | --- |
| `app/` | Pages and layout (Next.js App Router) |
| `components/` | Reusable UI pieces such as cards and buttons |
| `lib/api.ts` | Code that fetches data from the API |
| `lib/types.ts` | TypeScript types (`Question`, `ApiResponse`) |
| `.env.local` | Settings and secrets, never committed to Git |

<Callout type="info">
  Keeping API code separate from UI code is a good habit. If the API changes, you only update `lib/api.ts`.
</Callout>
