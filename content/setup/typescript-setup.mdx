# TypeScript Setup

We use **strict mode** so that mistakes are caught before the app runs.

## Create the project

```bash
npx create-next-app@latest quiz-app --typescript --tailwind --app --eslint
cd quiz-app
```

This command sets up TypeScript, Tailwind CSS and the App Router for you.

## Check strict mode

Open `tsconfig.json` and make sure `strict` is `true`:

```json filename="tsconfig.json"
{
  "compilerOptions": {
    "target": "ES2017",
    "strict": true,
    "noUncheckedIndexedAccess": true,
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```

- `strict: true` turns on all important type checks.
- `noUncheckedIndexedAccess` forces you to handle `undefined` when reading from arrays, such as `questions[0]`.
- `@/*` is an import alias, so you can write `import { Question } from '@/lib/types'`.

## Write the types first

Describe the shape of the API response before writing any other code:

```ts filename="lib/types.ts"
export interface Question {
  category: string
  type: 'multiple' | 'boolean'
  difficulty: 'easy' | 'medium' | 'hard'
  question: string
  correct_answer: string
  incorrect_answers: string[]
}

export interface ApiResponse {
  response_code: number
  results: Question[]
}
```

<Callout type="warning">
  Avoid the `any` type. If the API response does not fit a type, fix the type instead of hiding the problem with `any`.
</Callout>
