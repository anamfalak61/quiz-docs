# Dependencies

This project needs very few packages.

## Included with `create-next-app`

| Package | Purpose |
| --- | --- |
| `next`, `react`, `react-dom` | The framework |
| `typescript`, `@types/*` | TypeScript support |
| `tailwindcss` | Styling |
| `eslint` | Code quality checks |

## Optional: axios

```bash
npm install axios
```

| Package | Purpose |
| --- | --- |
| `axios` | An alternative to `fetch` that throws on 4xx and 5xx responses |

<Callout type="info">
  `axios` is not required. The [Implementation guide](/guides/implementation) uses the built-in `fetch` first and shows the `axios` version as well.
</Callout>

## Weather icons

You do not need an icon package. The weather API returns an icon code such as `10d`, and the image is loaded from the API provider's own icon URL. You will use it in the [UI & Styling guide](/guides/ui-styling).

## Run the project

```bash
npm run dev
```

Open `http://localhost:3000`. If you see the default Next.js page, your setup is complete.
