# Dependencies

This project needs very few packages.

## Included with `create-next-app`

| Package | Purpose |
| --- | --- |
| `next`, `react`, `react-dom` | The framework |
| `typescript`, `@types/*` | TypeScript support |
| `tailwindcss` | Styling |
| `eslint` | Code quality checks |

## Extra packages (optional)

```bash
npm install axios lucide-react
```

| Package | Purpose |
| --- | --- |
| `axios` | An alternative to `fetch` with simpler error handling |
| `lucide-react` | Category icons |

<Callout type="info">
  `axios` is not required. This guide uses the built-in `fetch` first and also shows the `axios` version.
</Callout>

## Run the project

```bash
npm run dev
```

Open `http://localhost:3000`. If you see the default Next.js page, your setup is complete.
